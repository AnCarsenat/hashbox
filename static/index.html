Guidelines

      
hashbox is a small, free tool run by one person. There are no accounts and no moderators,
        so it is built to keep as little as possible, for as short a time as possible.


      
What happens to what you share

      
    
        
  • Text and URL links are stored inside the link itself. This server never receives their content.
    • 
        
  • Chat messages and live clipboard pass through this server's memory only, and disappear about
          2 minutes after everyone has left. Nothing is written to disk.
    • 
        
  • Clipboard drops stay in memory until they are opened (if set to delete after viewing)
          or for 10 minutes at most.
    • 
        
  • is.gd links are created by is.gd, a separate service, and kept by them permanently.
    • 
        
  • No logs of content are kept. Like any web server, this one sees your IP address while you
          use it, to apply rate limits; it isn't stored.
    • 
      


      
Don't use hashbox to

      
    
        
  • share malware, phishing pages, scams or links to them;
    • 
        
  • share anything illegal, above all sexual content involving minors;
    • 
        
  • harass, threaten or dox anyone, or share someone's private information without consent;
    • 
        
  • send spam, or automate the site to flood it;
    • 
        
  • share passwords, bank details or other secrets: anyone with a link or code can see them.
    • 
      


      
How safety works without moderators

      
    
        
  • Links never redirect automatically: you always see the real destination and decide.
    • 
        
  • Links in chat are not clickable.
    • 
        
  • Everything expires by itself, and every feature has size and rate limits.
    • 
        
  • The operator can switch off any feature immediately if it is being abused.
    • 
      


      
Report abuse

      

      
Because content isn't stored, there is usually nothing to delete afterwards: a chat or clipboard
        is gone minutes after it's closed. For a link, the content is in the link itself, so please also report it
        to the site it points to, or to Google Safe Browsing.
